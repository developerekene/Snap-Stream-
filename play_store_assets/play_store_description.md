## Long Description

SnapStream is an offline photo and video file explorer with a built-in media editing studio. On first launch, SnapStream scans your device's local storage to organize every picture and video by folder, file size, and date—without needing an internet connection or account.

### Key Features

**Device Media Explorer**
- Automatically indexes photos and videos across Camera, Screenshots, Downloads, Pictures, Movies, and custom device folders.
- Switch instantly between **Grid view** and **List view** to browse thumbnails or detailed file metadata including resolution, duration, folder path, and file size.
- Filter by media folder, Favorites, Edited items, or Large Files (>10 MB) to spot space-consuming media quickly.
- Sort files by newest, oldest, largest, smallest, or alphabetical order, and search locally by file or folder name.
- Multi-select mode lets you batch-share, favorite, or delete multiple photos and videos at once.

**Built-in Photo & Video Studio**
- Apply 8 color filter presets (Original, Electric, Vivid, Noir, Warmth, Cyber, Matte, Cinema) with adjustable intensity.
- Fine-tune brightness, contrast, and saturation with real-time previews.
- Crop photos with draggable corner handles and aspect-ratio presets (Free, 1:1, 4:3, 16:9, 9:16, 3:4), rotate 90°, or flip horizontally.
- Trim video clip start and end times and save edited photos directly back to your device's gallery.

**100% Offline & Privacy-First**
- Works completely offline with zero network calls, zero ads, and zero tracking.
- Inspect real internal storage usage and free space directly inside the Storage & Settings tab.
